# 🎲 Yatzy Game (JavaScript)

Полностью играбельная игра **Yatzy**, построенная на **Vanilla JavaScript**, HTML и CSS.  
Проект фокусируется на чистом разделении игровой логики, ясном управлении состоянием UI и классических правилах Yatzy.

---

## 📖 Об Игре

**Yatzy** — это игра в кости, где цель — набрать наивысший общий счет, выбирая категории на основе комбинаций костей.

- Вы играете **одну игру** с **15 категориями**
- Каждая категория может быть использована **только один раз**
- Игра заканчивается, когда **все категории заполнены**

---

## 🎮 Как Играть (Правила, Используемые в Этом Проекте)

### 🎲 Кости и Раунды
- Вы бросаете **5 костей**
- У вас есть **до 3 бросков за раунд**
- После каждого броска вы можете **удерживать кости**, которые хотите сохранить
- Удерживаемые кости не бросаются снова
- После выбора категории раунд сбрасывается

---

### 🧮 Категории Подсчета Очков

#### Верхняя Секция
| Категория | Правило |
|--------|------|
| Единицы – Шестерки | Сумма костей с этим значением |

**Бонус Верхней Секции**
- Если общий счет верхней секции **63 или больше**, вы получаете **+50 бонус**
- Бонус добавляется автоматически к общему счету
- Вы можете выбирать категории в любом порядке (современные правила)

---

#### Нижняя Секция
| Категория | Правило |
|--------|------|
| Пара | Наивысшая пара |
| Две Пары | Две разные пары |
| Три Одинаковых | Три одинаковые кости |
| Четыре Одинаковых | Четыре одинаковые кости |
| Фулл Хаус | Одна пара + три одинаковых |
| Малый Стрит | 1–2–3–4–5 |
| Большой Стрит | 2–3–4–5–6 |
| Yatzy | Пять одинаковых костей (50 очков) |
| Шанс | Сумма всех костей |

---

### 🏁 Конец Игры
- Игра заканчивается, когда **все категории использованы**
- Появляется экран **Game Over**
- Финальный счет включает:
  - Все выбранные очки категорий
  - Бонус верхней секции (если заработан)

---

## 🧠 Технические Особенности

- Четкое разделение ответственности:
  - `YatzyLogic` — правила игры и подсчет очков
  - `YatzyDOM` — рендеринг и обновления UI
- Без фреймворков — **чистый JavaScript**
- Полностью детерминированная логика подсчета очков
- Адаптивный макет с масштабированием костей
- Чистый сброс состояния и обработка перезапуска
